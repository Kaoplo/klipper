# klipper

An instant replay application for linux!

## Building prerequisites 

- Install obs-studio on your system for `libobs`, a needed dependency for this application
- Build the project with cmake
- symlink `obs-ffmpeg-mux` next to the klipper binary

## Running

- Execute the klipper binary
- When the "Pick a Window" prompt pops up, pick a window/screen
- The application will record a 10-second video of your screen and stop automatically
